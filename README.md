## 🤖 Bundled Agent Skills (`skills/`)

This repository includes **16 specialized Agent Skills** (`SKILL.md`) that teach AI coding assistants (Google Antigravity, Claude Code, Cursor) how to execute battle-tested architectures without prompt drift:

1. **`production-readiness-audit`**: Exhaustive 46-point pre-launch checklist covering security, database concurrency, SEO, and SRE.
2. **`voice-agent-architect`**: Sub-300ms real-time conversational Voice AI system design (WebRTC, Silero VAD, token-streaming TTS).
3. **`url-to-design-tokens`**: Crawls benchmark websites to extract design tokens into a grounding `DESIGN.md`.
4. **`flash-sale-concurrency`**: Zero-overselling flash sale architecture with Redis Lua scripts, Kafka queues, and 10-min lease rollbacks.
5. **`colpali-rag-architect`**: Multi-vector vision-language RAG for PDFs, balance sheets, and blueprints using PaliGemma.
6. **`cloud-vps-hardening`**: Production VPS hardening: Nginx leaky-bucket rate limiting, ClamAV upload quarantine, and Cloudflare WAF.
7. **`high-throughput-caching`**: Stampede prevention using XFetch probabilistic early refresh and client-side single-flight mutex queues.
8. **`claude-prompt-architect`**: Anthropic's 5-part XML prompt architecture (`<role>`, `<context>`, `<instructions>`, `<constraints>`, `<output_format>`).
9. **`geo-seo-optimizer`**: 8-tactic Generative Engine Optimization tier list for SearchGPT/Perplexity citations and GSC CTR mining.
10. **`meta-ads-architect`**: Broad Advantage+ testing matrices, 72h stabilization rules, and CAPI offline qualification attribution loops.
11. **`stickman-video-director`**: Veo 3 OverSimplified-style historical battle and explainer animation storyboards and scripts.
12. **`remotion-automated-reels`**: Programmatic React-to-video reels using Claude Code, OpenAI TTS, Whisper timestamps, and Remotion.
13. **`hyperframes-video-engine`**: Compiles semantic HTML/CSS markup into deterministic MP4 videos via Headless Chrome and FFmpeg.
14. **`code-motion-graphics-suite`**: 5 code-driven motion graphic workflows (OneTake, Collage B-Roll, Sprite Rigging, Lemo Opuscar).
15. **`programmatic-reels-engine`**: Autonomous short-form video batch pipeline enforcing 1.5s hooks and 0.6s event frequency.
16. **`animated-explainer-director`**: 6 core studio animation patterns (process flows, panning timelines, 2s wipes, 3x detail zooms, hub maps, myth flips).

## 🚀 Local Development & Preview

Because the academy is built with vanilla HTML, modern CSS tokens, and lightweight vanilla JavaScript, it requires **zero build steps or heavy node_modules dependencies**:

```bash
# Clone the repository
git clone https://github.com/krushang007/reelvault-academy.git
cd reelvault-academy

# Serve locally using any static web server
npx serve .
# or Python
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
