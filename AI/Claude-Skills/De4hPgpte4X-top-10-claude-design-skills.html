    Top 10 Claude Design Skills for Web and UI Design

    Reel by @madetoscale2026 61 sHinglishshared 25 Oct 2026

    Library / AI / Claude-Skills

    A curated ranking of 10 Claude design skills (totaling 4.7 lakh GitHub stars combined) designed to eliminate generic AI styling ("purple slop") and generate production-ready UI, 3D landing pages, and system diagrams straight from prompts. The #1 ranked skill alone, UI UX Pro Max, accounts for 1.25 lakh stars.

    Steps

    1. Install the all-in-one design foundation UI UX Pro Max (125k stars) to enforce styles (Minimal, Brutalist, Glass, Editorial), curated font pairings (e.g. Inter + Lora, Space Grotesk), and UX constraints (44px tap targets, 4.5:1 contrast, single primary CTA). (00:43–00:48)
    2. Lint out generic AI styling using Taste Skill and Hallmark; Hallmark specifically detects and strips purple gradients, emoji headings, repetitive 3-card layouts, and generic CTAs. (00:21–00:24, 00:39–00:41)
    3. Convert wireframes to code using Stitch Skills (Google Stitch designs straight to clean HTML/CSS) or clone existing sites using Website Cloner ($ clone reference-site.com). (00:13–00:16, 00:32–00:35)
    4. Generate technical visuals directly from natural language using Archify (plain English to architecture diagrams) and Diagram Design (41 diagram types styled in brand colors). (00:28–00:31, 00:36–00:38)
    5. Build interactive presentations and immersive pages using Frontend Slides (web-page-style presentations) and Scroll World (3D brand scroll landing pages). (00:17–00:20, 00:25–00:27)
    6. Audit layouts and accessibility with Interface Skills for 8pt grid alignment, font sizing, and 7:1 contrast compliance. (00:09–00:12)
