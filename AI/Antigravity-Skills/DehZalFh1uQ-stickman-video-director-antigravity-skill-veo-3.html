    AI Stickman Video Director: Open-Source Antigravity Agent Skill for Veo 3 Explainer Animations

    Author: @codernormie Source: Instagram Reel DehZalFh1uQ Extracted: 2026-10-27

    A specialized Google Antigravity (AGY) agent skill and prompt harness discovered by Normie (@codernormie) based on the open-source GitHub repository AI Stickman Animation Style Collection (referenced as stickman-video-director). Equips autonomous AI coding agents with the capability to generate scripts, dynamic storyboards, sound effect prompts, and render high-retention stick-figure historical battles and scientific explainer videos (popularized by channels like OverSimplified) via Google DeepMind's Veo 3 generative video model.

    Core Capabilities & Pipeline Architecture

    1. Skill Integration into Antigravity: Clone or install the skill manifest into your Antigravity agent configuration (.agents/skills/stickman-video-director/SKILL.md). This grants the agent domain-specific knowledge of stick-figure composition rules, movement physics, and multi-character staging.
    2. Topic & Script Generation: Provide an overarching topic (e.g. The Napoleonic Wars or How Microprocessors Work). The skill instructs the agent to draft:
      • Paced Animation Scripts: Conversational, punchy narration with comedic pacing.
      • Dynamic Storyboards: Scene-by-scene framing definitions specifying camera movements, character flags, marching routes, and tactical overlays.
      • Voice-Over & SFX Prompts: Synchronized acoustic cues for footsteps, drum rolls, musket fire, and comedic sound effects.
    3. Generative Video Synthesis with Veo 3: The agent feeds the structured style descriptors and storyboards into Google's Veo 3 generative video model, producing coherent, temporal-consistent stick-figure movement without manual animation software.
    4. Target Formats: Optimized for YouTube historical/knowledge documentaries, TikTok/Reels educational explainers, and fast-paced popular science.

    Referenced Technologies & Tools

    • AI Stickman Animation Style Collection / stickman-video-director: Open-source MIT repository containing curated prompt harnesses, storyboarding templates, and character presets for stick-figure animation.
    • Google Antigravity (AGY): Autonomous agent IDE and runtime supporting custom installed skill definitions in .agents/skills/.
    • Google DeepMind Veo 3: High-definition generative video foundation model generating temporal-consistent 1080p animation from detailed prompts.

    Try This (Setting up in Antigravity)

    1. Create a new skill folder: .agents/skills/stickman-video-director/.
    2. Add a SKILL.md defining role instructions for script writing, OverSimplified visual rules (minimalist limbs, high-contrast black ink, colored division flags), and Veo 3 prompt parameters.
    3. Prompt the agent: "Use stickman-video-director to draft a 60-second animated explainer script and Veo 3 scene prompts for the Battle of Marathon."
    4. Review the generated storyboards and submit the prompt sequences to the Veo 3 API or Google AI Studio for batch rendering.
